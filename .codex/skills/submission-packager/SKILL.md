# Purpose

Prepare a read-only inclusion plan for one paper Markdown and one `支撑材料/` directory after the submission audits. The current restricted script raises `C2_UNQUALIFIED` at the start of `assemble()`, before staging, copying, reproduction, publication, or replacement. Package-layout and manifest rules below remain prerequisites and format definitions for any future separately approved publication-capable version, not permission to execute it now. Preserve selected code, inputs, and outputs under their workspace-relative paths. The packaged code must retain its module imports, CSV parsing, and normal working-directory paths. A packaging manifest stays outside the package at `planning/submission_packaging_manifest.json`.

# Preconditions

- `planning/session_config.json` selects `rigor_profile: submission`.
- Every `planning/manifests/Qx.json` is at G6 and allows final assembly.
- `paper/audits/cross_media_consistency_audit.md`, `paper/audits/completeness_audit.md`, and `paper/qa_report.md` each contain an explicit `Verdict: PASSED` line. Ask the relevant auditor to record the verdict when an older report omits it; do not infer passage from file existence.
- The paper and freezes have not changed after those audits. Renew affected audits when they have.
- Each Qx has a current `frozen_numbers.json`. Its source files identify one successful experiment round; verify that round's actual run_summary and real scripts/inputs/outputs under the currently deployed script's contract. The deployed restricted script reads Legacy top-level summaries and supported `schema_version: 1` `methods[]` summaries, maps current-plan identities and validation records, and checks the combined `output_files` and `figure_files` scope. These are structural checks, not certification of human authorization, actual execution, scientific acceptance, or publication safety; unversioned method-level summaries and unresolved evidence retain their existing blocks. Do not manufacture aggregates or rewrite original experiment records to satisfy packaging. Never select a round by its number alone.
- A final `paper/main.md` exists, or supply another Markdown with `--paper`.

If the human explicitly authorizes packaging before G6, record their choice and rationale as a `DECIDED` human `packaging_waiver` in a decision ledger. The existing `--allow-unaudited` parameter preserves that gate/audit scope for read-only planning only in this restricted version; it cannot enable assembly or publication. A waiver is not G6 approval or C2 qualification. Any future separately approved package manifest must retain the waiver and every failed gate or audit; never label it G6-approved.

- The manifest records evidence hashes, exact source-to-destination mapping, gate and audit evidence, selected frozen rounds, the confirmation digest, package hashes, and runtime status.
